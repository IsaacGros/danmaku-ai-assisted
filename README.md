# Danmaku AI Assisted

A single-stage 2D bullet-hell (danmaku) boss battle prototype built in **Unity** using **C#** as part of the project for **COSC 4272** AI-assisted software development project.

**Repository:** `https://github.com/IsaacGros/danmaku-ai-assisted`

## Overview

This prototype implements a playable single-stage boss encounter featuring coroutine-driven boss movement and attack patterns, projectile object pooling, dynamic screen-boundary math, and UI state management.

## Controls

- **Move:** `WASD` or Arrow Keys
- **Focus Mode (Precision Movement & Hitbox Display):** Hold `Left Shift` or `Right Shift`
- **Fire:** `Z` or `Space`.
